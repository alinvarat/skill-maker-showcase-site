# maker-showcase-site

Build or fix the user's personal/PULSE showcase website (alinvarat.github.io) or GitHub profile, including 3D robots and boards made from the user's real FreeCAD, KiCad or EasyEDA files. Use for bio/link pages, portfolio pages, 3D product scenes and publishing work to GitHub.

This is an agent skill: `SKILL.md` tells an AI coding agent such as Claude Code when to use it and which steps to follow.
